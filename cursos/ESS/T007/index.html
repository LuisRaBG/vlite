Escuchar para entender: Método narrativo e incidentes críticos para el trabajo con comunidades

INTRODUCCIÓN

Domine el arte de escuchar activamente para superar los prejuicios del investigador o facilitador externo. Analizaremos el método de incidentes críticos como una vía para detonar reflexiones a partir de las experiencias del otro.

Estudiaremos los lineamientos éticos fundamentales para documentar y proteger la voz de las comunidades mediante el consentimiento informado y el registro narrativo respetuoso.
